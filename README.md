# 防错设计（poka-yoke-design）

面向工艺/质量工程师的防错（Poka-Yoke）设计技能。核心是"遇到问题，用防错方式解决"——基于新乡重夫方法论，按 E-R-F-D-M 五大原则与十大原理主动构思候选方案，用"不制造>不传递>不接受"效果等级优选，输出可落地的防错设计方案。覆盖设计植入与现产缺陷再发防止。

## 适用岗位
- 工艺工程师（PE）：新品/新工艺植入防错，或现产缺陷设计防错再发防止。
- 质量工程师（QE/SQE）：把客诉/SPC 异常/审核发现转化为防错设计需求。
- 设计工程师：在 DFMEA/PFMEA 阶段前置策划防错。

## 解决的核心痛点
- 只会给现有装置"评审定级"，不会从问题出发设计方案。
- 分级混乱：把"提醒"当"拦截"，不懂"不制造>不传递>不接受"优先级。
- 过度依赖人眼 100% 检验，疲劳漏检。
- 只在末端拦截，未推动源头消除。
- 方案无依据，缺原则框架与选型基准。

## 方法论（权威框架）
- **本质**：不依赖人的注意力/技能/记忆，通过装置/流程/系统设计让错误无法发生或极易被发现（新乡重夫，精益核心方法）。
- **三大效果等级（优先级）**：不制造缺陷（最优）> 不传递缺陷 > 不接受缺陷（最被动）。
- **五大实施原则 E-R-F-D-M**：消除 / 替代 / 简化 / 检测 / 缓和。
- **十大经典原理**：断根、保险、自动、相符、顺序、隔离、复制、层别、警告、缓和。
- **五类技术方法**：失效-安全装置、传感器放大、冗余机制、倒计数/并行检查、特殊控制装置。
- **推行八步法**：成立小组→识别问题→根因分析→方案构思→评估选型→实施验证→运行监控→标准化推广。

## 产出物
- `防错设计方案_YYYYMMDD.txt`：纯文字版设计方案，适合评审流转/打印。
- `防错设计方案_YYYYMMDD.md`：结构化 Markdown 设计方案。

## 快速开始
```bash
# 直接运行，使用内置小样本（密封圈漏装）产出样例 TXT+MD（写到当前目录）
python scripts/build_report.py

# 基于自有 JSON 数据生成
python scripts/build_report.py --input 你的数据.json --out-dir 你的目录

# 只生成纯文字版 / 只生成 Markdown
python scripts/build_report.py --format txt
python scripts/build_report.py --format md
```

## 说明
- 所有文档为简体中文；效果等级与原则映射为通用参考，企业具体准则「待企业补充」。
- 本技能只产出防错设计提案，物理可行性与最终实施由工艺/设备工程确认；不替用户拍板。
